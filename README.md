# Cologuri Client Site (কোলোগুড়ি ভ্রমণকারী পোর্টাল)

বাংলাদেশের ভ্রমণপ্রেমীদের জন্য আধুনিক, রেসপনসিভ ও রিয়েল-টাইম ট্যুর বুকিং প্ল্যাটফর্ম।

## প্রযুক্তি স্ট্যাক (Tech Stack)
- **ফ্রন্টএন্ড ফ্রেমওয়ার্ক**: React 19 + Vite
- **স্টাইলিং**: Tailwind CSS v4 + কাস্টম বাংলা টাইপোগ্রাফি (Tiro Bangla, Hind Siliguri, Noto Sans)
- **স্টেট ম্যানেজমেন্ট**: Zustand
- **রিয়েল-টাইম কানেকশন**: Socket.io-client
- **আইকন**: Lucide React + Material Symbols

## প্রধান ফিচারসমূহ (Key Features)
1. **লাইভ জয়েন্ট ট্যুর**: বর্তমান সচল ট্যুর প্যাকেজ ও লাইভ সিট স্ট্যাটাস।
2. **স্মার্ট সার্চ ও ফিল্টার**: লোকেশন, তারিখ ও যাত্রী সংখ্যার ভিত্তিতে ট্যুর ফিল্টারিং।
3. **ইন্টারেক্টিভ সিট প্ল্যান**: লাইভ সিট নির্বাচন ও রেস-কন্ডিশন প্রটেকশন।
4. **সহজ বুকিং ও চেকআউট**: bKash, Nagad, কার্ড পেমেন্ট সাপোর্ট।
5. **কাস্টম ট্যুর রিকোয়েস্ট**: নিজস্ব ভ্রমণ পরিকল্পনা পাঠানোর সুবিধা।

## সেটআপ ও রান করার নিয়ম (Setup & Run)

```bash
# ১. ডিপেন্ডেন্সি ইনস্টল
npm install

# ২. এনভায়রনমেন্ট তৈরি
cp .env.example .env

# ৩. ডেভেলপমেন্ট সার্ভার চালু
npm run dev

# ৪. প্রোডাকশন বিল্ড
npm run build
```
